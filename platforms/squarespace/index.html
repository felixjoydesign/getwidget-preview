FAQ

Squarespace FAQ

Which Squarespace plans support custom code?

Scripts in Code Blocks and Code Injection need a Core, Plus or Advanced plan, or an older Business or Commerce plan.

Can I place widgets on specific pages?

Yes. Use a Code Block on any page to embed a widget exactly where you want it.

Will it match my Squarespace template?

Set the widget's colors and layout in the builder, or import your site's styles, so it fits your template.
