Where to paste it

Where the code goes in Shopify

It depends on where the widget should show. Pick the case that matches, then follow the steps.

theme.liquid

On every page

Floating widgets like chat buttons

theme.liquid is the main layout file of your Shopify theme, so code pasted there loads on every page.

  1. Go to Online Store > Themes > Edit code and open theme.liquid.
  2. Paste both snippets just before the closing </body> tag.
★★★★★
Custom Liquid section

In one spot on a page

Anywhere on a page, with Online Store 2.0 themes

Custom Liquid is a section you add in the theme editor: Online Store > Themes > Customize > Add section.

  1. Go to Online Store > Themes and click Customize.
  2. Click Add section > Custom Liquid where the widget should appear.
  3. Paste both snippets into a Custom Liquid section to place a widget on a page.
