How to add widgets to Wix

01 01

Build your widget

Pick a widget type, customize the design and preview it live in the builder.

02 02

Copy the embed code

Click Install in the builder and copy both snippets: a script tag and a div.

03 03

Add to Wix

For chat buttons, banners and popups, go to Settings > Custom Code, paste both snippets and load them on all pages. For inline widgets like reviews or forms, add Embed Code > Embed HTML where the widget should appear, paste both snippets and resize the box.

FAQ

Wix FAQ

Do I need Wix Velo for this?

No. You only paste the embed code. No Velo development needed.

Do I need a premium Wix plan?

Settings > Custom Code needs a premium plan with a connected domain. The Embed HTML element works on any plan.

Will it work on Wix mobile view?

Floating widgets added through Custom Code adapt to phone screens. Embedded HTML boxes keep the size you set, so check them in Wix's mobile editor.
