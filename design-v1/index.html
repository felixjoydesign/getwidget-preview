What is GetWidget?

GetWidget is a no-code website widget builder. Pick a widget, customize it in a visual editor and add it to any website with one embed code.

How it works

Live on your site in three steps

No plugins to install and nothing to redeploy. If your site can load a script, it can run GetWidget.

  1. 01

    Pick a widget

    Choose from 16 widgets for reviews, chat, forms, banners and more.

  2. 02

    Make it yours

    Set colors, layout and content in the visual editor, with a live preview as you go.

  3. 03

    Paste the embed code

    Add the embed code to your site once. When you edit the widget later, your site updates on its own.

index.html 
<!-- in <head> -->
<script src="https://static.getwidget.com/scripts/testimonial.js" async></script>

<!-- where the widget appears -->
<div class="get-widget-id-YOUR_ID"></div>

Platform guides

Works with WordPress, Shopify, Wix, Squarespace, Webflow and any website

No plugin or app to install. If your site can load a script, it can run GetWidget.

  • 01

    Widgets for Shopify

    Go to Online Store > Themes > Edit code and open theme.liquid.

    Read the guide
  • 02

    Widgets for WordPress

    In the block editor, add a Custom HTML block where the widget should appear and paste both snippets.

    Read the guide
  • 03

    Widgets for Squarespace

    Edit the page, add a Code Block where the widget should appear, paste both snippets and save.

    Read the guide
  • 04

    Widgets for Webflow

    In the Webflow Designer, add a Code Embed element where the widget should appear.

    Read the guide
  • 05

    Widgets for Wix

    For chat buttons, banners and popups, go to Settings > Custom Code, paste both snippets and load them on all pages.

    Read the guide
