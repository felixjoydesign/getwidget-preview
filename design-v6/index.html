How it works

Live on your site in three steps

No plugins to install and nothing to redeploy. If your site can load a script, it can run GetWidget.

  1. 01

    Pick a widget

    Choose from 16 widgets for reviews, chat, forms, banners and more.

  2. 02

    Make it yours

    Set colors, layout and content in the visual editor, with a live preview as you go.

  3. 03

    Paste the embed code

    Add the embed code to your site once. When you edit the widget later, your site updates on its own.

Step-by-step guides for Shopify, WordPress, Squarespace, Webflow and Wix.

index.html 
<!-- in <head> -->
<script src="https://static.getwidget.com/scripts/testimonial.js" async></script>

<!-- where the widget appears -->
<div class="get-widget-id-YOUR_ID"></div>
