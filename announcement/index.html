    What is a Announcement Bar widget?

    An announcement bar is a thin strip of text at the top or bottom of a website. It carries one short message, like a sale, a new feature or a shipping update, often with a button that links to the details.

    GetWidget builds it in a visual editor. Write your message, add a button, a badge or an image, pick your colors and paste one embed snippet.

    01 · Content
    A one-line message, emojis welcome, with an optional badge or image
    02 · Button
    Your own label, linking to any page
    03 · Positions
    Top or bottom of the screen, or inline in your page
    04 · Close button
    Optional. A closed bar stays hidden for the rest of the visit
    05 · Free plan
    2 widgets and 250 views a month, free forever
    06 · Paid plans
    From $4/mo billed yearly ($5 billed monthly)

    Platform guides

    Works with WordPress, Shopify, Wix, Squarespace, Webflow and any website

    No plugin or app to install. If your site can load a script, it can run GetWidget.

    • Widgets for Shopify

      Go to Online Store > Themes > Edit code and open theme.liquid.

      Read the guide

    • Widgets for WordPress

      In the block editor, add a Custom HTML block where the widget should appear and paste both snippets.

      Read the guide

    • Widgets for Squarespace

      Edit the page, add a Code Block where the widget should appear, paste both snippets and save.

      Read the guide

    • Widgets for Webflow

      In the Webflow Designer, add a Code Embed element where the widget should appear.

      Read the guide

    • Widgets for Wix

      For chat buttons, banners and popups, go to Settings > Custom Code, paste both snippets and load them on all pages.

      Read the guide
