    What is a Testimonial widget?

    A testimonial widget shows quotes from your customers on your own website. Each card carries the customer's words with their name, photo, role and a star rating, so new visitors hear from people like them.

    GetWidget keeps every testimonial in one place. Add them by hand or sync a Google Sheet, then show them anywhere with one embed code.

    01 · Sources
    Added in the builder, or synced from a Google Sheet
    02 · Layouts

    03 · Testimonials
    No limit on how many you add
    04 · On each card
    Quote, name, role, photo and a 1 to 5 star rating
    05 · Free plan

    Platform guides

    Works with WordPress, Shopify, Wix, Squarespace, Webflow and any website

    No plugin or app to install. If your site can load a script, it can run GetWidget.

    • Widgets for Shopify

      Go to Online Store > Themes > Edit code and open theme.liquid.

      Read the guide

    • Widgets for WordPress

      In the block editor, add a Custom HTML block where the widget should appear and paste both snippets.

      Read the guide

    • Widgets for Squarespace

      Edit the page, add a Code Block where the widget should appear, paste both snippets and save.

      Read the guide

    • Widgets for Webflow

      In the Webflow Designer, add a Code Embed element where the widget should appear.

      Read the guide

    • Widgets for Wix

      For chat buttons, banners and popups, go to Settings > Custom Code, paste both snippets and load them on all pages.

      Read the guide
